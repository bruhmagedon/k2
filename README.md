## Расчёт

Рунге — Кутта 4-го порядка реализован в `src/lib/model.ts`, без готового решателя ОДУ.

\[
x_1'=x_2,\quad x_2'=\frac{cu-r(x_1)x_2^2}{x_3}-g,\quad x_3'=-u.
\]

Параметры: c = 6500, u = 35, g = 9,81; X(0) = (1000; 0; 1090).
Для чётного варианта r определяется линейной интерполяцией таблицы 5, за её границами — крайними значениями. h_тв = 9990 в чётном варианте не используется.

По общему заданию T = 10 с; в таблице варианта T = 12 с. Доступны оба значения, по умолчанию 10 с.

Относительная погрешность: `δ = |x₁(T; h) − x₁(T; h/2)| / |x₁(T; h/2)| · 100%`. Множитель 1/15 не применяется: по методичке эталоном служит результат с h/2.

Автоподбор делит исходный шаг пополам до δ ≤ 1%. Итоговый график и x₁(T) относятся к принятому h. Это первый подходящий шаг в последовательности делений, а не глобальный максимум h.

Последний шаг сокращается до точного T. J — число шагов основного решения, без уточняющего прогона. Анализ сравнивает 10 пар h и h/2, начиная с введённого h. Ось h логарифмическая.

Расчёты выполняются в Web Worker с отменой. Для графика сохраняется не более 1001 точки; само интегрирование выполняется на всех шагах. Общий бюджет одного запроса — 50 млн шагов, включая уточняющие расчёты.

Тема: [VS Code, tweakcn](https://tweakcn.com/r/themes/cmm0993hl000004jmdjmx96j3), применена через shadcn CLI. Интерфейс использует тёмную палитру пресета.
